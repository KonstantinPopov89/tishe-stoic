# Тише. Стоицизм в карточках

Устанавливаемое веб-приложение по книге Массимо Пильюччи "Как быть стоиком. Античная философия и современная жизнь".

63 адаптированные карточки: истории, визуальные схемы, ситуации с выбором, необязательные квизы и 17 практических карточек, в том числе все 12 упражнений из главы 14. В каждом объяснении есть привязка к книге. Редакционные ситуации и иллюстрации обозначены отдельно.

## Пользоваться

Листай вверх и вниз. При первом открытии порядок задан заранее. Кнопка с двумя стрелками перемешивает карточки. В семи историях можно раскрыть развязку на самой карточке, а затем перейти к следующей идее. Истории, вопросы и практики чередуются; раскрывать историю или отвечать на квиз необязательно. "Разобраться" открывает контекст и источник. Закладка сохраняет карточку. "Хочу попробовать сегодня" также добавляет практику в сохраненное; снятие этой отметки сохраняет закладку. Подборка "Попробовать сегодня" включает 17 практических карточек. В разделе "О книге" можно увеличить текст.

На iPhone открой ссылку в Safari, выбери "Поделиться", затем "На экран Домой". При наличии переключателя включи открытие как веб-приложения. После первой полной загрузки приложение может работать без сети; браузер вправе очистить кэш. Избранное, ответы и место чтения сохраняются только на текущем устройстве.

## Локальный запуск

Открой `index.html` из этой папки. Для установки и офлайн-кэша нужен HTTPS либо локальный HTTP-сервер:

```sh
python3 -m http.server 8000
```

Затем открой http://localhost:8000.

Приложение не требует сборки, внешних библиотек или аккаунта. Статические файлы можно размещать на GitHub Pages. При изменении файлов нужно менять имя кэша в `sw.js`. Обновленная версия активируется после закрытия вкладок старой версии.

## Содержание

Это редакционный отбор по книге, а не ее полная электронная копия. Исторические и научные утверждения передают позицию источника и не прошли сплошную внешнюю проверку. Современные ситуации, краткие схемы и иллюстрации созданы для ленты. Просмотр карточек не доказывает усвоение материала или изменение привычек.

Исходный EPUB и полный реестр экстракции в репозиторий не включены. Права на книгу остаются у ее правообладателей.
